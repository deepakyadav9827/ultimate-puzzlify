# **App Name**: Enigma Nexus

## Core Features:

- Puzzle Selection Hub: A refined interface allowing players to choose between various logic game archetypes including Sudoku, Sliding Puzzles, and Memory grids.
- AI Logic Weaver: An AI-powered generator that acts as a tool to create unique, logically sound puzzles based on player-selected difficulty and complexity constraints.
- Dynamic Responsive Grids: Highly performant and interactive game boards that adapt to different screen sizes while maintaining precision control.
- Insightful Mentor: A generative AI hint system that acts as a tool to analyze the current game state and provide strategic nudges without giving away the full solution.
- Progress Serialization: Locally stored session state to allow players to resume complex puzzles across different browsing sessions.
- Success Analytics: Visual data representations of solving speed, move efficiency, and complexity progression.

## Style Guidelines:

- The palette is inspired by 'Deep Cognitive Focus'. A dark theme is utilized to reduce eye strain during prolonged play sessions.
- Primary color: Electric Slate Blue (#5C7AFF) for a high-tech intellectual feel. Background: Midnight Deep Sea (#0A0C10) for maximum depth and contrast.
- Accent color: Celestial Teal (#2AC3DE) used for highlight indicators and success states, providing a clear analogous contrast to the primary blue.
- Font pairing: 'Space Grotesk' (sans-serif) for high-impact headlines to convey a modern, scientific feel; paired with 'Inter' (sans-serif) for readable body text and small instructional details.
- Geometric line-based icons with subtle gradients to match the precision-driven nature of logic games.
- A minimalist, focused layout centering the game board with floating toolbars to ensure a zero-distraction environment.
- Micro-interactions include kinetic scale transitions when tiles are placed and subtle neon glow pulses for successful logic connections.
